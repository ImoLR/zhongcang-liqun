# 重仓利群（Android）

在手机上开本地端口，NekoBox、FlClash、v2rayNG、Clash Meta 等代理客户端都能直接连。重仓利群**不用 VPN，不占系统的 VPN 位置**；系统 VPN 留给你自己的代理客户端。

它替你完成 LeiKwan 商家的设备认证、线路授权和续期，用内置的商家官方转发核心在 `127.0.0.1` 上开出每条转发的本地端口。代理客户端里把节点地址改成 `127.0.0.1` 和对应端口，就走商家的线路。本应用不是商家官方客户端。

这个仓库**只用来下载**，没有源码（源码不公开，也没有附带开源许可）。

## 下载

- 最新版：<https://github.com/ImoLR/zhongcang-liqun/releases/latest>
- 每个版本的页面上有 APK 和 `SHA256SUMS`。下载后可以核对：`sha256sum -c SHA256SUMS`（或在手机上用任意文件校验工具对比 SHA-256）。
- 支持 Android 8.0 及以上，64 位 ARM（以及 x86_64），不需要 root。新版直接覆盖安装，账号和设置保留。

## App 内更新（1.0.3 起）

- 1.0.3 起重仓利群会自己检查新版本：打开 App 时、开着时每 30 分钟、连接中每小时一次，也可以在 设置 → App 更新 里点「检查更新」。
- 它读的是这个仓库里的 `update.json`（通过 GitHub，或者镜像 gh-proxy.com、ghfast.top、jsDelivr——国内直连 GitHub 常常不通）。这个文件带签名，App 只认签名对的；检查只是下载这一个公开文件，不带任何手机或账号信息。
- 有新版本时会提示「有新版本 x.y.z」。点「更新」就在 App 里下载（GitHub 不通或太慢会换镜像），核对文件的 SHA-256 后交给系统安装。第一次要允许重仓利群「安装未知应用」（App 会带你去那一页）；大多数手机安装时还要点一下「安装 / 更新」。连着的时候更新，连接会断几秒，装完自动恢复。
- 管理员可能要求更新：版本太旧时不能新连接（已经连着的不断），或者整个 App 停用（只显示一页说明和下载链接，正在用的连接会停）。这个要求断网、重启都会保留，直到更新或者管理员解除。
- **1.0.2 及以前没有这个功能**：先从下面的链接手动装一次 1.0.3（覆盖安装，账号和设置保留），以后就在 App 里更新。

## 第一次使用

1. 安装 APK，打开重仓利群。首页（套餐流量下面）有四张新手卡片（1.0.5 起）：电池设为「无限制」、节点地址 127.0.0.1、分应用代理里绕过、彩蛋：换个图标？点开看说明，点「我知道了」收起；电池那张在电池设成「无限制」后自己消失。想再看一遍：设置 → 关于 →「重新显示新手卡片」。
2. 齿轮 → **账号**：三项一起填——商家网站「客户端」页面上的「客户端 ID」和「Agent Token」，以及「账户安全 → API 令牌」里的令牌（App 里叫「转发管理令牌」，和 Agent Token 不是同一个）。点「确认」：检查格式、用转发管理令牌读一次商家的服务列表（令牌不对会在这一栏说明），保存后回到首页。三项只保存在这台手机上（系统加密）。没填全时，点「连接」「添加转发」「编辑」「删除」都会提示先去填。
3. **电池设为「无限制」（必须）**：点「连接」时如果电池优化还开着，会先弹出说明，点「去设置」在系统窗口里选「允许」。电池优化开着时，锁屏后系统会冻结或关掉后台服务，代理客户端就会断线。小米 / 红米、华为、荣耀、OPPO / 一加 / 真我、vivo / iQOO、三星还有自己的后台管理开关（应用读不到），设置 → 电池 里有对应手机的提示和「打开应用设置」按钮，照着改成「无限制 / 允许后台活动」。
4. 点 **连接**。首页按专线列出账号里的转发（「利群·广港 CAN → HKG」、沪日、广台、福台、京德），展开一条可以看到本地地址（`127.0.0.1:端口`，可复制）、落地和状态。顶上是 名额 · 专线 · 转发 · 在线设备（这个客户端在线的设备 / 上限），下面「套餐流量」是本周期已用 / 套餐包含（1 GB = 1024³ 字节），点 ＋ 看剩余和到期。这些数字来自商家的转发 API，和列表一起刷新。
5. 在代理客户端里设置（见下一节），然后就可以用了。不用时点「断开」。

## 配合代理客户端

**原则**：重仓利群要放在代理客户端的 VPN **外面**，不然它自己连线路的流量会绕回代理。要用客户端**设置里的「分应用代理 / 访问控制」**把它排除（绕过、黑名单或「不允许已选应用」）。**不要用路由或规则里的「按应用直连 / 绕过」代替**：那样它的流量还是先进 VPN，客户端事后才判断，规则没匹配上或客户端重启时就会绕回代理。

各客户端的菜单（按各客户端源码里的中文菜单名，2026-11 版本）：

- **NekoBox**：☰ 菜单 → **设置** → 「路由设置」里的「分应用代理」→ 打开 → 选「绕过」→ 勾选重仓利群 → 返回，按提示重载代理。是「设置」里的分应用代理，不是左侧菜单的「路由」。
- **FlClash**：底栏「工具」→ 「设置」里的「访问控制」→ 右上角菜单 → 开启 → 模式选「黑名单模式」→ 勾选重仓利群 → 保存，按提示重启 VPN。不要用「进阶配置 → 附加规则」里的进程（PROCESS-NAME）规则代替。
- **v2rayNG**：☰ 菜单 → 「分应用设置」→ 打开「启用分应用」和「绕行模式」→ 勾选重仓利群 → 重新连接。不要用「路由设置」里的包名（process）规则代替。
- **Clash Meta for Android**：先在主页停止 Clash → 设置 → 网络 → 「访问控制模式」选「不允许已选择的应用」→ 「访问控制应用包列表」勾选重仓利群 → 返回再启动。订阅里的 PROCESS-NAME 规则不能代替这一步。

**节点**：复制要走专线的原节点，**只把节点地址改成 `127.0.0.1` 和本地端口**，其它（协议、密码、加密方式等）照落地填。其他节点不用改。

## 预热池（设置 → 连接保护）

一个勾选框，默认勾上。勾上后每条转发提前和线路建好几条空连接，打开网页、App 时少等一下。只在亮屏、最近 5 分钟用过时预热；息屏不预热、不耗电。

**要配合转发面板使用**：空连接会一直连到落地，所以落地要支持 **120 秒的空连接等待**（转发面板的落地是这样设置的）。自己搭的落地通常几秒就关掉没有数据的连接（例如 xray 默认 4 秒），这时预热池没有用——但也可以开着：**重仓利群会自动检测**，一条转发的空连接一再在几秒内、几乎同一时间被落地关闭，就**只关闭这条转发的预热池**，转发本身照常用，其它转发不受影响；首页展开这条转发会写「落地不支持预热，已自动关闭这条转发的预热池」。商家中转偶尔断掉一两条空连接不算。改了这条转发的落地或端口、或把预热池关掉再打开，会重新检测；否则最多每 24 小时试一次，能撑过 60 秒就自动恢复。

## 添加、编辑、删除转发

首页「＋ 添加转发」、每条专线里的「在这条专线添加转发」、展开一条转发后的「编辑」「删除」通过商家的转发 API 完成：要先在 设置 → 账号 填好转发管理令牌，并且先点「连接」。改一条只影响这一条：编辑时这条重连一次（正在用它的连接会断开），其它转发不受影响。在商家网站上改的，App 也会自己跟上（最长约 30 秒）。

## 常见问题

- **连上了但代理客户端连不通**：先看重仓利群首页这条转发是不是「就绪」；再检查客户端里是不是已经把重仓利群排除在 VPN 外（上面「配合代理客户端」），节点地址是不是 `127.0.0.1` 和这条转发的本地端口。
- **锁屏一会儿就断**：电池没有设成「无限制」，或者手机自己的后台管理把它关了（设置 → 电池 里有提示）。实在不行可以在 设置 → 电池 打开「息屏时保持唤醒」（更耗电）。
- **提示「商家在线设备已满」**：这台手机在商家那里算一台设备。先在另一台设备（或另一个 App）里断开，稍等再连；不会踢掉别的设备，约每分钟自动重试。
- **提示「商家要求更新客户端版本」或「商家不接受本机核心版本」**：到这里下载最新版覆盖安装。
- **预热池显示「已自动关闭」**：这条转发的落地不支持空连接等待，转发本身照常可用，只是没有预热。
- **会不会连别的服务器？** 重仓利群自己只连商家官方 HTTPS 地址、本机 `127.0.0.1`，以及检查更新时的这个 GitHub 仓库（或它的镜像 gh-proxy.com、ghfast.top、gcore.jsdelivr.net，只读公开的 `update.json` 和安装包）；内置的商家官方核心按商家的授权连接商家的入口。没有统计、广告或其它服务器。
- **出问题怎么排查**：设置 → 运行日志 → 导出，发给帮你排查的人。运行日志只记本机事件（最多 2 MB），不含密码、令牌或流量内容。
- **换了 App 图标后桌面上找不到了**：设置 → App 图标 可以在「利群 logo」和「群主头像」之间换。部分桌面要几秒才更新，个别桌面会把主屏图标移走，需要从应用列表重新拖出来。
- **怎么回到旧版本**：Android 不能直接装比现在版本号低的 APK。先卸载重仓利群（账号要重新填），再安装旧版的 APK（每个版本的发布页都保留着）。
